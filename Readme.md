#  Project Overview

Hello! Reviewer, I see you have stumbled upon me, read me, well, be astounded, for this is a device that is meant to be used by old people out of touch with technology. 

---

###  The Problem & Inspiration
* My own grandma struggles to open websites or apps like YouTube on my laptop.
* But with this and a click of a button, BOOM, the YouTube page is open.
* Apart from jokes, I just want people out of touch with technology to be able to use it properly.
* I want them not to dislike it just because it is complicated; I want them to be able to properly get used to it.

---

###  Key Features
* **One-Click Automation**: Instantly opens target pages like YouTube.
* **Status Display**: Has a screen to show exactly what the device is doing.
* **Proximity Activation**: Includes a sensor that turns it on whenever my grandma is near it.

---

##  Hardware Requirements

To build this project, you will need the following components:
* **Microcontroller**: Arduino, 
* **Proximity Sensor**: HC-SR04 Ultrasonic sensor
* **Display Screen**: OLED display or 16x2 LCD screen
* **Physical Input**: Tactile push button, or preferably a 3d printer
* **Connection**: USB cable to connect to the computer

---

##  How It Works & Installation

### 1. Hardware Setup
Connect your Macropad. 
* Trigger the screen to wake up when the sensor detects a person nearby.
* Program the button to send a keyboard shortcut or serial command to your computer when pressed.

---

### Assembly
* Make sure you have all the materials.
* First, take the PCB, then place it inside the shell (the biggest part, looks unfinished)
* After that, place the PCB with the shell inside the frame. (the one with a beautiful-looking hole for charging and connecting)
* Then glue the top cover in (the one with and 45mm by 45mm hole in it.)
* then just place the keycap holder.
* then pop the keycaps in (With springs)
